# Capstone Overview
This repository implements three different machine learning models to accurately give a percentage of injury for NFL players based on their position, surface playing field, and more. This repository also visualizes the comparisons between certain features such as play counts on either turf or natural grass, the playcounts per position, etc. 

The Random Forest Classifier model worked best when predicting the injury rate of NFL Players based on multiple features
There was no significant difference in injury rate between the two fields due to the lack of data from the original dataset itself
All data was oversampled in order to come to the conclusion and visualization of performance metrics of each model
